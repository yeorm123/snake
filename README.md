# 👀 컴퓨터에게 "보는 법" 가르치기 — 웹캠 AI 실습 강의노트

> 오늘 한 실습 네 가지를 정리한 노트입니다.
> 코딩을 처음 해 보는 사람도 따라 할 수 있도록 쉬운 말로 썼습니다.

| 차시 | 실습 | 한 줄 요약 | 파일 |
|---|---|---|---|
| 1 | 🐍 포즈 뱀게임 | 몸동작으로 뱀을 움직이는 게임 | `index.html` |
| 2 | 📦 객체 인식 (Detection) | 화면 속 물건을 찾아 **네모 박스**를 그림 | `webcam_detect.py` |
| 3 | ✂️ 누끼 (Segmentation) | 물건의 **윤곽선을 따라** 정확히 오려냄 | `webcam_segment.py` |
| 4 | 🏃 추적 (Tracking) | 움직이는 물건에 **번호표**를 붙여 계속 따라감 | `webcam_track.py` |

## 0. 시작하기 전에: AI는 어떻게 "보는" 걸까?

컴퓨터 입장에서 사진은 **숫자로 된 아주 큰 표**입니다.
점(픽셀) 하나하나가 "빨강 얼마, 초록 얼마, 파랑 얼마" 하는 숫자로 되어 있지요.

AI 모델은 사진을 **수만~수백만 장** 보면서 "이런 숫자 패턴이면 고양이, 이런 패턴이면 사람" 하고 규칙을 스스로 익힙니다.
이렇게 공부하는 과정을 **학습(training)**, 공부를 끝낸 AI를 **모델(model)** 이라고 부릅니다.

오늘은 남이 미리 공부시켜 둔 모델을 가져다 썼습니다. 이런 모델을 **사전학습 모델**이라고 합니다.

- 1차시: 구글의 **Teachable Machine**으로 **내가 직접** 모델을 가르쳤습니다.
- 2~4차시: **Ultralytics**라는 회사에서 만든 **YOLO26** 모델을 썼습니다.

> 💡 **YOLO**는 "You Only Look Once(한 번만 본다)"의 줄임말입니다.
> 사진을 **한 번 훑어보는 것만으로** 물건을 모두 찾아내서 빠릅니다. 그래서 웹캠처럼 실시간 영상에 잘 맞습니다.
> 뒤에 붙은 **26**은 버전 번호입니다.

## 1차시. 🐍 포즈 뱀게임 (Teachable Machine)

### 무엇을 만들었나요?
키보드 대신 **몸동작**으로 뱀을 조종하는 게임입니다.
팔을 위로 들면 뱀이 위로, 옆으로 뻗으면 옆으로 움직입니다.

### 어떻게 동작하나요?
1. **Teachable Machine**(구글이 만든 무료 웹사이트)에서 `up`, `down`, `left`, `right` 네 가지 자세를 각각 여러 번 찍어 모델에게 보여줍니다.
2. 모델은 몸의 관절 위치(어깨, 팔꿈치, 손목 등 = **키포인트**)를 보고 "지금 어떤 자세인지" 맞히는 법을 배웁니다.
3. 게임은 웹캠 화면을 계속 모델에게 보여 주고, 모델이 답한 자세대로 뱀의 방향을 바꿉니다.

### 실수를 줄이는 장치
- **임계값**: 모델이 "이 자세일 확률 70%" 처럼 답하는데, 이 확률이 기준보다 낮으면 무시합니다. 화면의 슬라이더로 기준을 바꿀 수 있습니다.
- **안정화**: 같은 자세가 **몇 프레임 연속** 나와야 방향을 바꿉니다. 잠깐 몸이 흔들려서 엉뚱한 방향으로 가는 일을 막아 줍니다.
- 키보드 방향키로도 조종할 수 있습니다.

### ▶️ 실행 방법
설치할 것은 없습니다. 웹 브라우저(크롬 추천)만 있으면 됩니다.

1. `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
   - 웹캠이 안 켜지면 터미널에서 `python -m http.server` 를 실행한 뒤 브라우저에서 `http://localhost:8000` 으로 접속하세요.
2. 카메라 권한을 **허용**합니다.
3. 시작 버튼을 누르고 몸으로 뱀을 움직여 보세요!

## 2차시. 📦 객체 인식 (Object Detection)

### 무엇을 하나요?
화면 속에 **무엇이 / 어디에** 있는지 찾아서 **네모 박스**와 이름표를 붙입니다.

```
┌────────────┐
│ person 0.92│  ← "사람이고, 92% 확신해요"
│            │
└────────────┘
```

- 사람, 컵, 휴대폰, 의자, 강아지 등 **80가지** 물건을 알아봅니다. (COCO라는 유명한 사진 모음으로 공부한 모델이라서 그렇습니다.)
- 숫자(0.92)는 **신뢰도**, 즉 모델이 얼마나 확신하는지를 나타냅니다.

### 코드 핵심만 보기
```python
model = YOLO("yolo26n.pt")      # ① 모델 불러오기
ok, frame = cap.read()          # ② 웹캠에서 사진 한 장 가져오기
results = model(frame)          # ③ 모델에게 "뭐가 보여?" 물어보기
annotated = results[0].plot()   # ④ 결과를 사진 위에 그리기
cv2.imshow("...", annotated)    # ⑤ 화면에 보여주기
```
영상은 사실 **사진을 빠르게 넘기는 것**이라서, ②~⑤를 계속 반복하면 실시간 인식이 됩니다.
1초에 몇 장을 처리했는지가 화면 왼쪽 위의 **FPS** 숫자입니다.

### ▶️ 실행 방법
```bash
python webcam_detect.py
```

옵션을 붙여서 바꿔 볼 수도 있습니다.

| 옵션 | 뜻 | 예시 |
|---|---|---|
| `--model` | 모델 크기 (`n` < `s` < `m` < `l` < `x`). 클수록 정확하지만 느림 | `--model yolo26s.pt` |
| `--cam` | 웹캠 번호 (노트북 내장 = 0, 외장 = 1) | `--cam 1` |
| `--conf` | 이 확신도보다 낮으면 박스를 안 그림 | `--conf 0.5` |
| `--imgsz` | 모델에게 보여줄 사진 크기 | `--imgsz 320` |

```bash
python webcam_detect.py --model yolo26s.pt --conf 0.5
```

## 3차시. ✂️ 누끼 따기 (Segmentation)

### 무엇을 하나요?
객체 인식은 네모 박스까지만 그려 줍니다. 그런데 사람은 네모 모양이 아니죠.
**세그멘테이션**은 물건의 **윤곽선을 따라 픽셀 단위로** 정확하게 칠해 줍니다.
포토샵에서 "누끼 딴다"고 하는 바로 그 작업을 AI가 자동으로 해 주는 것입니다.

| 객체 인식 | 세그멘테이션 |
|---|---|
| "여기쯤 사람 있어요" (네모) | "정확히 이 모양이 사람이에요" (실루엣) |

### 객체 인식과 뭐가 다른가요?
코드는 거의 같습니다. **모델 이름만 바뀝니다.**
```python
model = YOLO("yolo26n-seg.pt")   # 끝에 -seg 가 붙은 모델
```
이 모델은 박스와 함께 **마스크**(물건이 있는 곳은 1, 없는 곳은 0으로 표시한 그림)를 같이 돌려줍니다.

`--cutout` 옵션을 켜면 이 마스크를 써서 **배경을 까맣게 지우고 물건만 남깁니다.** 진짜 누끼 따기죠!
```python
annotated = frame * mask   # 마스크가 0인 곳(배경)은 0(검정)이 됨
```

### ▶️ 실행 방법
```bash
python webcam_segment.py            # 물건 위에 색을 칠해서 보여주기
python webcam_segment.py --cutout   # 배경을 지우고 물건만 남기기 (누끼 모드)
```
`--model`, `--cam`, `--conf`, `--imgsz` 옵션은 2차시와 똑같이 쓸 수 있습니다.

## 4차시. 🏃 추적 (Tracking)

### 무엇을 하나요?
객체 인식은 사진 한 장 한 장을 **따로따로** 봅니다. 그래서 "1초 전의 사람"과 "지금의 사람"이 **같은 사람인지** 모릅니다.

**추적**은 물건마다 **번호표(ID)** 를 붙이고, 다음 장면에서도 **같은 물건에는 같은 번호**를 계속 붙여 줍니다.

```
1번째 장면: person id:1   person id:2
2번째 장면:   person id:1     person id:2   ← 조금 움직였지만 번호 유지!
```

이걸로 할 수 있는 일:
- 가게에 들어온 손님 **수 세기** (같은 사람을 두 번 세지 않음)
- 자동차가 **어느 방향으로** 가는지 알아내기
- 운동선수의 **이동 경로** 그리기

### 어떻게 같은 물건인지 알아요?
**트래커(tracker)** 라는 알고리즘이 "바로 전 장면에서 이 근처에 있던 물건이니까 같은 물건이겠다" 하고 위치와 움직임을 비교해서 짝을 지어 줍니다.
- `bytetrack.yaml` (기본값): 빠르고 가벼움
- `botsort.yaml`: 생김새까지 비교해서 조금 더 정확함

### 코드 핵심만 보기
```python
results = model.track(frame, persist=True)   # model(frame) 대신 model.track(...)
ids = results[0].boxes.id                    # 각 물건의 번호표
```
- `persist=True`: "이전 장면을 **기억해 둬**"라는 뜻입니다. 이걸 빼면 매번 번호가 새로 매겨집니다.
- 이 실습에서는 물건마다 지나온 길을 **노란 꼬리선**으로 그려서 움직임을 눈으로 볼 수 있게 했습니다.

### ▶️ 실행 방법
```bash
python webcam_track.py
python webcam_track.py --tracker botsort.yaml   # 다른 트래커 써 보기
python webcam_track.py --trail 60               # 꼬리선을 더 길게
```

## 📝 오늘 배운 것 한눈에 보기

| | 뱀게임 | 객체 인식 | 누끼 | 추적 |
|---|---|---|---|---|
| 질문 | "지금 무슨 자세야?" | "뭐가 어디 있어?" | "정확히 어떤 모양이야?" | "아까 그 물건 지금 어디 있어?" |
| 결과 | 자세 이름 | 네모 박스 | 실루엣(마스크) | 박스 + 번호표 |
| 모델 | Teachable Machine (직접 학습) | `yolo26n.pt` | `yolo26n-seg.pt` | `yolo26n.pt` + 트래커 |
| 코드 차이 | — | `model(frame)` | 모델 이름에 `-seg` | `model.track(frame, persist=True)` |

같은 YOLO26이라도 **모델 이름**과 **함수 한 줄**만 바꾸면 전혀 다른 일을 시킬 수 있다는 점이 핵심입니다.

## 🛠️ 자주 생기는 문제

| 증상 | 해결 방법 |
|---|---|
| `웹캠 0번을 열 수 없습니다` | 다른 프로그램(줌, 카톡 영상통화 등)이 카메라를 쓰고 있는지 확인하세요. 외장 웹캠이면 `--cam 1` 을 붙여 보세요. |
| `pip` 이 없다고 나옴 | 파이썬 설치할 때 "Add Python to PATH"를 체크했는지 확인하세요. `python -m pip install ...` 으로 해도 됩니다. |
| 너무 느려요 (FPS가 낮음) | `--imgsz 320` 처럼 사진 크기를 줄이거나, 가장 작은 `n` 모델을 쓰세요. NVIDIA 그래픽카드가 있으면 자동으로 더 빨라집니다. |
| 엉뚱한 물건을 찾아요 | `--conf 0.5` 처럼 기준을 높이면 확실한 것만 표시합니다. |
| 뱀게임 웹캠이 안 켜져요 | 브라우저 주소창 왼쪽의 자물쇠 아이콘에서 카메라를 허용하거나, `python -m http.server` 로 열어 보세요. |
